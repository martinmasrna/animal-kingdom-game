# Rulings audit (2026-11-05)

Every ruling in `docs/rules/rulings.md` (98 bullets and the "A unit uncovered by a removal" paragraph, 99 in all) against the engine: 204 tests in `animal_kingdom/tests/audit/test_rulings.py`, named `test_<section>__<ruling>`, in the document's order. Assertions come from the ruling's words.

Results: 85 ok, 0 engine fixed, 2 two readings, 1 engine wrong and not fixed, 11 contradict a card's printed text or the card data. Most of the contradictions are rulings that went stale when a card's text changed. The ruling describes an older card, and the engine follows the printed text. Each one has a test of what the text does now (or a strict xfail where the ruling's own words can still be tested), so the doc can be brought up to date. The doc and the card text were not edited.

Rust mirror: no engine change was made, so no file in `engine_rs/src` needs a matching change. If the two open engine questions below are settled toward the ruling, the Python is in `animal_kingdom/engine/effects.py` (`_bush_dog_roam`, `_push_reactions`/`_op_queen_guard`, `_cockroach_legend_remove`) and the Rust mirror is the matching file in `engine_rs/src` (effects).
