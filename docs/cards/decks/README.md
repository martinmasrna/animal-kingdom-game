# The starter decks

Every deck is 30 cards in the 4-4-6 shape: 4 legendary designs ×1, 4 rare ×2, 6 common ×3. `animal_kingdom/data/cards.json` holds every card, written by the card table; each deck doc's card table is generated from cards.json (`.venv/bin/python -m animal_kingdom.render.deck_docs`) and a test fails when one goes stale. Edit the prose by hand, never the tables.
